# Review with the Founder and three test users (A6)

This is the script and record sheet for the M2 review. The prototype is static, so a session needs only a phone browser (or a desktop browser at 360 px wide) and the link to `prototype/index.html`.

## Who

- The Founder, who leads the session and signs off.
- Test user 1: reads English, uses the app in light mode.
- Test user 2: reads Arabic, uses the Arabic screens (right to left).
- Test user 3: uses the app in dark mode with large text (browser zoom at 200 percent).

## Tasks, about 10 minutes per person

1. From the first run screen, name the citizen and reach the lobby.
2. Start a chat with the citizen and find where to write a message.
3. Find the three services (learn, create, earn) and open one.
4. Find the credits balance and the daily spending limit.
5. In Settings, switch the theme and the language, then find how to delete the citizen.

## After the sessions

- Every task a person could not finish without help becomes a change, made before the Founder signs off.
- The Founder notes the sign off and the changes in this file.
